Sobre a Plataforma

Objetivo do Projeto

Criar uma plataforma centralizada onde entusiastas de cinema e séries podem descobrir novos conteúdos, organizar suas watchlists e compartilhar avaliações.


Solução Oferecida

O 2ZWatch oferece uma experiência completa de descoberta de conteúdo audiovisual, com autenticação segura via Google OAuth 2.0, sistema de favoritos persistente e avaliações de usuários com média de ratings.

Funcionalidades Principais

  • Autenticação via Google OAuth 2.0
  • Sistema de favoritos e watchlist persistente
  • Avaliações de usuário com média de ratings
  • Busca e filtros avançados
  • Interface responsiva e moderna
  • Integração com TMDB API

Funcionalidades Futuras

  • Sistema de recomendações personalizadas
  • Comentários e reviews detalhados
  • Compartilhamento social de listas
